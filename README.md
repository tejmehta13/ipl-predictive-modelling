# IPL Predictive Modelling

## Overview
Machine learning project predicting IPL 2026 outcomes using historical IPL data.

## Techniques Used
- Logistic Regression
- Random Forest
- XGBoost
- Monte Carlo Simulation
- ELO Ratings
- Feature Engineering

## Data
- 283,000+ ball-by-ball records
- Match-level data
- Squad and auction data

## Key Findings
- Punjab Kings: 28.2% title probability
- RCB: 27.6%
- SRH: 17.2%

## Technologies
- R
- tidyverse
- tidymodels
- xgboost
- ggplot2
